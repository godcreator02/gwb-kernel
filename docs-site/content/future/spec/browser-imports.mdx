## 已定接口

内核提供 `registerImports(mapping)`，返回注销函数，插件用 `ctx.effect` 管理。只接受精确包名到本地模块文件 URL。
页面在动态 import 前调用 `window.gwb.prepareImports(required?)`；准备请求串行读取当前登记快照，完成 DOM 注入后才返回。
已注入的地址改变或撤销时拒绝新的准备，要求整页重载；同一文档不尝试改绑或假装卸载模块。

kernel 负责主进程插件启动及页面模块解析环境；React 的版本和产物由 shell 提供。不同提供方通过普通代码出口交付
无副作用的 `browserImports()`，构建与运行时复用。没有包清单共享字段，也不扫描 home 发现提供方。
