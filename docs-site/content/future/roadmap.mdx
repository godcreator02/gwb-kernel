# 路线

**本页回答**：内核接下来可能改哪些地方、每一项在等什么前提条件。这些都还没做；已经在做的事在[交接区](/spec)，已经决定不做的在[关键设计](/docs/design)。

每一项都要满足[准入判据](/docs/design#准入判据)的第二个条件：前提条件满足了——某件事此刻确实做不成，而且说得出具体场景——才动手。

| 可能要做的 | 在等什么 | 到时候要回答的问题 |
| --- | --- | --- |
| **把安装包分发给别人** | 确实要装到别人的机器上 | pnpm 怎么放进构建产物（本机的安装包不带 pnpm，安装插件用的是机器上已有的那一份） |
| **命令行** | 界面无法操作时，确实需要另一种操作方式 | 目前从安装版启动、把 `GWB_HOME` 与调试开关原样传给进程，这样是否仍然够用 |
| **多个 home 的管理界面** | 确实需要同时照看几个 home | 同时运行多个 home 本身已经是安全的；缺的是在几个 home 之间切换和总览的功能——它多半不该放在内核里 |
