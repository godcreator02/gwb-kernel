# 投来的反馈

**本页回答**：别的仓在用这个仓的东西的过程中投来了什么意见。一条一节：`## <日期> <一句话标题>`，

## 2026-09-15 devkit 0.12.0 改走安装包起 home——AGENTS「怎么跑」里那句验机口径过期了

来源：gwb-devkit（单元 260908dkv）0.12.0 发版收尾。devkit 从这版起不再 build 内核、不认内核仓：
`devkit.home.new` / `open` 拉宿主自己那个 exe（日常就是安装版，`GWB_HOME` 照认），`kernel-dir`
设置整体退役。内核源码的验机从此只剩本仓「怎么跑」那条 `pnpm start` + `GWB_HOME` 的路。建议把
AGENTS「怎么跑」里「验机走 `devkit.home.new`，它自己会 build」那句改口，别让人再指望 devkit 代劳。

## 2026-09-15 隔离 home 取证回执天然带两条 warn + 跨形态的清单识别

来源：同上。其一，底座七件里没有 theme 件，每个隔离 home 开机都产
`gwb-commands 跑了条不存在的命令：theme.startupCss`，外加一条 Electron CSP warn——每趟验机
回执都带着这两条，第一次见的人会去追不存在的病。建议要么底座补 theme，要么把这型
「缺件属正常」的 warn 降噪。其二，源码态宿主起的 home 清单里认不出安装版 default 在跑
（映像名既不是 electron 也不是宿主自己，两头不认；安装版宿主倒是全认得）——现象在 devkit
侧记了案，修法也可以住本仓（按 runtime.json 的 appDir 判据放宽映像核对），供参考。
