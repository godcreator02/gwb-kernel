# 交接

**本页回答**：现在有哪些进行中的工作、做到哪儿了、交给下一个会话要看什么。

这一区的规矩一句话：**有页 = 有工作在进行，做完删页**。一项工作一页，页头是验收清单，正文是实施方案；
边做边提交，中途每次提交都是一份可以交接的快照。做完把结论分别放回各自的位置——设计写进
[现状区](/docs)、决定写成一张 [轨迹卡](/trajectory)、没做的放回 [未来区](/future/roadmap)——
然后把那一页删掉。git 历史就是它的存档。这一页本身是导读，不算一项工作。

## 什么样的工作才单独写成一页

**跨会话、跨模块、有未定的选型**，三条满足一条才写 spec；一个会话做得完的，直接在模块页里写清楚就开工。
先把需求边界问清楚，问到能说清「回答什么 / 不做什么 / 成功判据」；选型用 `gwb-decide` 来问，
两件事不重叠。
