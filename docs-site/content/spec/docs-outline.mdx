## 页面怎么写

- **接缝页**：`本页回答` 一句 → 两侧各是谁（一句话，指到两侧的包页）→ **交换什么**（钉码：类型、函数、配置）→ **两边各保证什么** → **一侧不管什么** → **怎么单独测**（钉测试）→ **代码从哪读**。点线接缝没有代码接口，「交换什么」写约定的内容和它写在哪
- **包页**（首页）：docfirst 的七段——管什么 / 不知道什么 / 数据结构 / 提供的接口（指到对应接缝页）/ 依赖的接口（表：接口、用来做什么、生产实现、测试实现）/ 怎么单独测 / 代码地图（在哪、先读、读序、可跳过）
- 现状页只写现状，不写历史；每页头一句「本页回答」；不说黑话
