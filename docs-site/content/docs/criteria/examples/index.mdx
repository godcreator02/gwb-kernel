# 标准例子

**本页回答**：关键判据落到具体的件上长什么样；看哪个例子学哪几条判据。

每个例子是这个件**按判据应该长成的样子**，不是它今天的样子；今天对不上的地方，在各页末尾「现状偏差」里留一行，迁移清单在[机制定案](/spec/ecosystem-simplify)。每页七段：角色、清单、产物里的裸名、面、契约、收尾、现状偏差。

| 例子 | 为什么挑它 | 主要示范 |
| --- | --- | --- |
| [E1 commands](/docs/criteria/examples/e1-commands) | 最底层的服务提供方 | 扩展点用服务；不按值 import cordis 就没有 peer；契约住自己包里（K2、K5、K6） |
| [E2 shell](/docs/criteria/examples/e2-shell) | importmap 的唯一提供方 | K3 提供方的全部规矩；服务只留扩展点（K2、K3、K5） |
| [E3 unit-folder](/docs/criteria/examples/e3-unit-folder) | 普通的带窗格件 | 数据与动作走命令；浏览器半怎么外置；回执类型导出（K2、K3、K5、K6） |
| [E4 块笔记](/docs/criteria/examples/e4-block-note) | 最复杂的件间关系 | 契约包、命令为本、在场标记、契约版本区间（K3、K4、K5、K6、K7） |
| [E5 node-cli](/docs/criteria/examples/e5-node-cli) | 会起子进程 | 卸载收尾的完整做法（K5、K7） |
