# E3 unit-folder（`@godcreator/gwb-unit-folder`）

## 角色

单元文件夹：扫单元容器根、读出生证，给人一个单元树窗格，给 agent 与别的件一组读写单元的命令。

## 清单

```json
{
  "keywords": ["gwb", "gwb-plugin"],
  "gwb": { "provides": { "gwbUnitFolder": { "summary": "…", "usage": "…" } } },
  "exports": { ".": "…", "./client": "…", "./style.css": "…" },
  "peerDependencies": { "cordis": "…" },
  "devDependencies": {
    "cordis": "…", "react": "…", "react-dom": "…",
    "@godcreator/gwb-plugin-api": "…", "@godcreator/gwb-shell": "…",
    "@godcreator/gwb-commands": "…", "@godcreator/gwb-data": "…", "@godcreator/gwb-settings": "…"
  }
}
```

peer 只有 `cordis`（`extends Service`）。shell 写 dev：取类型、构建期调 `@godcreator/gwb-shell/externals`、样式里引 `theme.reference.css`（[K2](/docs/criteria/k2)）。

## 产物里的裸名

node 半：`cordis` 与 node 内置。浏览器半：只有 react 四名，名单从 shell 的 `./externals` 取，不手抄（[K3](/docs/criteria/k3)）。

## 面

- **命令**是全部的数据与动作：`unit-folder.list`、`create`、`listDir`、`readFile`、`open`、`code`、`select`、`current`、`pin`、`unpin`、`toolbarButtons`——页面、agent、别的件都走这一套
- **服务** `gwbUnitFolder` 只留扩展点：`registerToolbarButton`（往单元树工具条放按钮），外加选中变化事件 `unit-folder/selection`
- 读当前选中、读置顶只走 `unit-folder.current` 与 `unit-folder.list` 两条命令，服务上不再有同义方法（[K5](/docs/criteria/k5)）

## 契约

导出每条命令的参数与回执类型（比如单元清单的形状）、工具条按钮的形状；调用方 `import type` 取（[K6](/docs/criteria/k6)）。

## 收尾

置顶清单落数据件，容器根住设置件；工具条按钮的登记随调用方卸载自动摘；起外部编辑器的进程是有意活过宿主的，detached 并写明（[K7](/docs/criteria/k7)）。

## 现状偏差

待改：构建脚本手抄外置名单；命令回执类型没导出；commands、shell、skills、词汇表包写成了 peer；服务上的 `current()` / `pinned()` 与命令重复。
