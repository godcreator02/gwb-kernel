# 术语表

**本页回答**：文档里那个词在这个仓里指什么。只收本仓造的词与在这里有特定含义的词，通用术语不收。

| 词 | 是什么 |
| --- | --- |
| **内核** | 这个仓的 Electron 应用本体：只做第一个件跑起来之前必须发生的事，其余一切皆件。见[从这里开始](/docs) |
| **件** | 插件：一个普通 npm 包，装在 home 里，由 cordis 挂载，跑在主进程 |
| **home** | 件住的地方，一个普通的 npm 项目根；一个 home 就是一套独立的世界。见[home](/docs/kernel/home) |
| **准入判据** | 两道关：第一个件存在之前必须发生的事才进内核；真遇到需求才加。见[边界](/docs/boundary) |
| **条目** | `cordis.yml` 里的一条：`id` 是身份（手写），`name` 是装哪个包。见[挂载](/docs/kernel/loading) |
| **挂上** | 条目的 fiber 到了 `ACTIVE`；有 fiber 不等于挂上。见[挂载](/docs/kernel/loading) |
| **热挂卸** | 运行中经条目树的 API 挂、改、卸一条条目，yml 随之写回；不是文件监听。见[挂载](/docs/kernel/loading) |
| **裸名解析** | 把包名（与子路径）解成 home 里的真实文件：node 半给 loader 用，浏览器半拼 importmap。见[挂载](/docs/kernel/loading)、[importmap](/docs/kernel/importmap) |
| **共享声明** | 包清单里的 `gwb.shared`：「我给页面提供这几个裸名」。见[importmap](/docs/kernel/importmap) |
| **外壳** | 调了 `setShell` 的那个件，页面的 `#root` 归它的默认导出。见[页面与桥](/docs/kernel/bridge) |
| **只读现状** | 没有外壳或外壳起不来时页面画的那份：各条目到哪一步、最近的错误行；不归因、没有按钮。见[页面与桥](/docs/kernel/bridge) |
| **命令总线** | 某个件提供的命令服务；页面的命令原样派给它。见[页面与桥](/docs/kernel/bridge) |
| **词汇表** | `@godcreator/gwb-plugin-api`：内核与件、页面之间的全部契约，纯类型。见[契约面](/docs/kernel/contract) |
| **三路日志** | 件、内核、页面 console 三个来源，汇成同一条 cordis 日志流。见[日志](/docs/kernel/logs) |
