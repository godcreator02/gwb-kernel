# 怎么跑、怎么验

读完这页你能回答：提交前要过哪道门禁；这个仓为什么只测纯逻辑；实机验收怎么做。

第一次跑、装件、home 在哪，见[跑起来](/docs/getting-started/first-run)——那页管「跑起来」，这页管「怎么验」。

## 门禁

```powershell
pnpm check   # typecheck 全仓 + oxlint + vitest
```

提交前跑它。它**不依赖构建产物**：typecheck、lint 和 vitest 吃的都是源码，所以「没 build」和
「门禁全绿」不冲突。整条约 3 秒，其中 lint 不到 0.3 秒。

`pnpm lint` 那段是 `oxlint . --type-aware --deny-warnings`，扫 **21 个 `.ts`**：`apps/desktop/src`
12 个（含 `env.d.ts`）、`tests` 6 个、两份配置（`electron.vite.config.ts`、`vitest.config.ts`）、
词汇表包 1 个。

**规则集就是 oxlint 的默认**——配置里一条 `rules` 都没写。默认是 870 条里的 111 条，几乎全在
correctness 这一类（`no-const-assign`、`no-dupe-keys`、`no-unreachable`、`use-isnan`、`missing-throw`
这种「几乎肯定是错的」），其中 16 条要类型信息。**style / pedantic / restriction 那些噪音类别默认
一条都不开**，所以「111 条」听着多，实际是 oxlint 自己筛过的结果，不是一堆风格意见。

**这个数是靠人记的**——将来加了新包、新目录，忘了它在不在某份 tsconfig 里，它会静默留在 lint 面
外，没有任何东西会说话。数不上就该去看一眼。

**文档站不在里面**：它钉 `typescript ^6.0.3`，而 type-aware 要 TS 7+，tsgolint 给它建不出 program。
它本来也不进根 build/test，自己有 `livedoc check` 与 `next build` 两道。

两个 flag 都不是装饰：**不带 `--deny-warnings`，有诊断也照样 `exit 0`**（屏幕上有红字而门禁放行）；
`--type-aware` 配置里已经开着，CLI 上再写一次是为了让「它没生效」变成看得见的错误，而不是静默
降级成非类型模式——那是这条门禁最危险的失败形态，因为一切看起来都绿。

## 写代码先写测试，但只测该测的

这个仓写逻辑之前先写测试。TDD 在这里最大的用处不是保证正确，是**它自己会把代码逼成可测的
形状**：写不出测试的那一刻，就知道该把纯逻辑从副作用里抠出来了。

但判据是**「跑它要不要起一个 Electron 或一个子进程」**，不是「这段重不重要」。眼下能测的：

| 测什么 | 在哪 |
| --- | --- |
| 行协议的解析与路由 | `src/shared/protocol.ts` |
| 条目解析、入口四档、位查找与越界 | `src/shared/entries.ts` |
| `gwb://` 的 URL 解析 | `src/shared/asset-url.ts` |
| 日志缓冲的发号、截断、攒批 | `src/main/logs.ts`（不打真 IPC） |
| 日志文件的切段与归档清理 | `src/main/log-file.ts`（跑真文件、不打真进程） |
| 命令通道的超时与死亡路径 | `src/main/host-process.ts`（假宿主，不真 spawn） |

其余——`spawn`、`BrowserWindow`、fd3 流、`protocol.handle`——一律归实机验证。
硬凑自动化只会得到一堆脆弱的桩。

## 实机验证怎么做

起一次，看两处：宿主的 stderr（挂载逐条结果）和渲染层的 console（主进程把它转到终端了）。
真 registry 的验收（发布、从 Verdaccio 装）走本机 Verdaccio，见[跑起来](/docs/getting-started/first-run)。

有个具体例子说明为什么实机不可省：home 分格第一次开测试 home 时撞出「全新 home 起不来」——
`cordis.yml` 不在，include 抛错落在挂载链上，宿主整个退出（见[那面墙](/docs/trajectory/2026-09-07-wall-fresh-home-no-yml)）。
**单测抓不着这个**：每个函数单看都对，是「从没被走过的一条路径」上才显形的组合问题。实机
起一次，宿主 exit 1，一眼就看见。

「验从零」要开干净 home——纪律见[跑起来](/docs/getting-started/first-run)末尾那节。
