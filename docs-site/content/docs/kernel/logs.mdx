# 日志

**本页回答**：日志从哪几路来、出口在哪、文件怎么防写爆、内核与件各管到哪儿。

## 管什么

内核铺唯一一个出口：stderr 加 `<home>/gwb.log`。cordis 的日志经内核挂的全量 exporter 进这个出口；内核自己的话与页面 console 也走 `ctx.logger`，于是三路汇成一条流。文件有上限、会轮转，出口自己出岔子绝不把内核带走。主进程的未捕获异常与没人接的 rejection 只记不退。

## 不知道什么

不为窗格铺日志管道、不自建缓冲——页面上要看日志的件自己挂第二个 exporter、从 cordis 自带的缓冲补历史、经 `gwbKernel.emit` 推给页面。日志格式不进契约面（[那张卡](/trajectory/2026-09-07-log-shape-not-in-vocab)）。不归因、不告警。

## 数据结构

- **一行**：`<ISO 时间> <级别> <名字> <正文>`，级别与名字照抄 cordis 那边的字符串，正文由 cordis 的 `Logger.format` 渲染
- **三路的名字**：件用自己的 logger 名；内核是 `kernel`；页面 console 是 `renderer`
- **文件**：现行一份 `gwb.log` 加滚下来的旧份；上限与留几份见下

## 提供的接口

**出口与上限**：`say` 同时写 stderr 与日志文件。上限走环境变量 `GWB_LOG_LIMIT_MB`（缺省见 `log-file.ts`；`0` = 不轮转、留全量；读不出数就用缺省），只留一份旧的。stderr 对端断了（没有终端起）每写一次抛 EPIPE，吞掉，文件照写（[那面墙](/trajectory/2026-09-08-wall-stderr-epipe)）。

**轮转**：按写进去的字节累加判断、不每条 stat；到上限先关句柄再改名、再重开，避免 fd 悬在改过名的文件上；开局就超限的上一轮文件，第一条日志就滚走。任何一步失败只说一句、继续往后写，轮转失败要再长一个上限才重试。

{/* ref file="../apps/desktop/src/log-file.ts" lines="121-164" */}

**全量 exporter**：在模块顶层、挂 loader 之前注册——cordis 没有 exporter 时只缓冲不输出，第一个挂不上的件的报错不能等（[那面墙](/trajectory/2026-09-07-wall-loader-error-swallowed)）。格式化失败有一层逐参数 `String` 的兜底。warn / error 到来时捅一下页面的只读现状（见[页面与桥](/docs/kernel/bridge)）。

{/* ref file="../apps/desktop/src/main.ts" lines="130-162" */}

**内核的话与只记不退**：内核自己的话走 `ctx.logger('kernel')`，不直接 `say`——这样件挂一个 exporter 就收齐三路。件跑在这个进程里，件的错就是这个进程的错，两个 `process.on` 只记不退。

{/* ref file="../apps/desktop/src/main.ts" lines="164-171" */}

**起不来那一句**：`main()` 抛出时直接 `say`（这时可能谁都没挂上），再弹错误框（见[挂载](/docs/kernel/loading)）。

## 依赖的接口

| 接口 | 用来做什么 | 生产实现 | 测试实现 |
| --- | --- | --- | --- |
| cordis logger 工厂（`exporter`、`buffer`、`Logger.format`） | 收流、渲染、给只读现状取最近错误行 | cordis | — |
| 文件系统 | 写 `gwb.log`、轮转 | `node:fs` | 真 fs 跑临时目录 |
| `GWB_LOG_LIMIT_MB` | 上限 | 起进程的那只手给 | `limitFromEnv` 直接喂字符串 |

## 怎么单独测

`log-file.ts` 不碰 electron 与 cordis，拿真 fs 跑临时目录：证明没到上限不轮转、超上限滚一份且只留约定的份数、轮转后新写的落进新文件、开局超限第一条就滚、上限 0 不轮转、轮转失败与开不出文件都不致命且只喊一句、`onWarn` 自己抛也不漏出去；`limitFromEnv` 覆盖缺省、正整数、0 与各种坏值（`tests/log-file.test.ts`）。「失败」用「目标位置被目录占着」造，那是 Windows 上真会撞的形态。
