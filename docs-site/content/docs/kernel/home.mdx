# home

**本页回答**：内核怎么决定用哪个 home、每次开机往里铺什么、为什么同一 home 开不出第二份、`runtime.json` 是什么。

## 管什么

在任何件存在之前，把 home 变成 cordis 起得来的地方：选定目录并归一成磁盘真实路径，补齐两个文件，拿到这个 home 的单开锁，写下这一轮进程的身份。全部在 `main.ts` 的模块顶层同步完成，先于 `whenReady`。

## 不知道什么

不知道 home 里装了哪些件、条目表里写了什么——铺的两个文件只保证「起得来」，不保证「有东西」。不碰 pnpm，不装任何包。不认识 `runtime.json` 里内核以外的字段（开门的件在里面补自己那一格）。不读、不清理别的 home。

## 数据结构

| 盘上 | 谁写 | 内核怎么对它 |
| --- | --- | --- |
| `<home>/package.json` | 缺了内核补一份最小清单，之后归 pnpm | 只补不改 |
| `<home>/cordis.yml` | 缺了内核补空表 `[]`，之后归 include | 只补不改；缺它整趟起不来（[那面墙](/trajectory/2026-09-07-wall-fresh-home-no-yml)） |
| `<home>/electron/` | Chromium | 这个 home 的 userData，也是单开锁的钥匙 |
| `<home>/runtime.json` | 内核 | 每轮开机整份重写，退出不删 |
| `<home>/gwb.log` | 内核 | 见[日志](/docs/kernel/logs) |

## 提供的接口

**home 的选法**：`GWB_HOME` 缺省是 `default`；给纯名字落 `<appData>/gwb-kernel/homes/<名>`；含路径分隔符就用那个目录本身。选定后 `realpath` 归一，同一个 home 的两种写法得到同一个串——单开锁靠它认出「同一个 home」。

**铺两个文件**：每次开机都跑，缺什么补什么，在的一律不覆盖。

{/* ref file="../apps/desktop/src/main.ts" lines="49-56" */}

**单开锁**：Electron 的平台锁，钥匙是上面那份按 home 拆开的 userData。同一 home 的第二个实例拿不到锁，stderr 报一句、退出码 1、不动 `runtime.json`；在跑那份把窗抬到前面。不同 home 随便并跑。判据见[单开锁](/trajectory/2026-09-12-one-home-one-instance)。

**`runtime.json`**：pid、起的时刻、内核版本、应用目录，开了 Chromium 调试口时再加一格 `cdp`（没开就没有这一格，不写 0 或 null）。每轮开机整份重写；退出不删——**读的人负责验活**（pid 活着、而且真持着那个口）。写不动只报一句 warn。判据见[运行时身份](/trajectory/2026-09-11-kernel-writes-runtime-record)。

{/* ref file="../apps/desktop/src/main.ts" lines="97-122" */}

**`dataDir` 是单源**：`ctx.baseUrl`、日志路径、`gwbKernel.dataDir` 都从它来；件要 home 路径只从 `gwbKernel.dataDir` 取（见[契约面](/docs/kernel/contract)）。

## 依赖的接口

| 接口 | 用来做什么 | 生产实现 | 测试实现 |
| --- | --- | --- | --- |
| `GWB_HOME` 环境变量 | 选 home | 起进程的那只手给 | 实机：每次验给一个隔离 home 名 |
| `app.getPath('appData')` / `app.setPath('userData')` | homes 根、按 home 拆 userData | Electron | — |
| `app.requestSingleInstanceLock` | 单开锁 | Electron | 实机：同一 home 起两次 |
| 命令行 `--remote-debugging-port` | `runtime.json` 的 `cdp` 格 | 起进程的那只手给 | — |

## 怎么单独测

没有纯函数可抽——这一段全是 Electron 与文件系统的顶层副作用，只在隔离 home 里实机验：全新 home 起得来、两个文件被补齐且已有的不被覆盖、同一 home 第二次起被拒、`runtime.json` 每轮重写。
