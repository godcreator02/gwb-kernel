---
title: 命令如何使用请求通道
description: commands 主动登记业务通道；内核传输未知载荷，命令语义全部由提供方处理。
---

<Diagram name="command-relay" title="commands 定义命令协议，内核只分发通道">
- 页面导入 commands 的纯浏览器客户端，调用 command(name, args)
- 客户端通过 window.gwb.request 发往 commands.run 通道
- 内核只按通道定位处理器并传递载荷与结果
- commands 校验名字、固定 via 为 ui，执行命令并返回业务回执
- 未登记的通道由内核拒绝；命令客户端将命令服务不可用映射为命令失败回执
</Diagram>

内核的契约见[请求通道](/docs/seams/requests)。命令载荷、来源、`GwbResult` 与客户端校验由基础插件仓的 `plugins/commands/src/page-request.ts`、`result.ts`、`client.ts` 定义。

内核不导入 commands，不查找其服务，不合成命令回执；commands 的登记跟随服务生命周期撤销。
