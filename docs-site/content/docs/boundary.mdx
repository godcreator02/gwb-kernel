# 边界

**本页回答**：内核此刻只做哪几件事；要往内核里加东西得过哪两道关；哪些东西内核刻意没有、理由去哪看。

## 只做什么

都是第一个件存在之前必须发生的事：

- **铺 home**：选目录、补两个文件、单开锁、写运行时身份——[home](/docs/kernel/home)
- **起 cordis 并挂件**：根上下文指向 home，挂官方 loader 与 include，补上 node 半的裸名解析，退出时拆树——[挂载](/docs/kernel/loading)
- **浏览器半的裸名**：收各包的共享声明拼成 importmap——[importmap](/docs/kernel/importmap)
- **开窗与桥、页面根**：一扇窗、三条 IPC，页面把 `#root` 交给外壳，没有外壳时画只读现状——[页面与桥](/docs/kernel/bridge)
- **自己出错人看得见**：唯一的日志出口，出错只记不退，起不来弹错误框——[日志](/docs/kernel/logs)

说这些事用的名词在[契约面](/docs/kernel/contract)。

## 准入判据：两道关，都得过

1. **凡是「第一个件存在之前必须发生的事」，才进内核。** 其余一律皆件
2. **真遇到需求才加。** 不是「将来可能要」「顺手做了吧」——是某件事此刻就干不成，而且说得出现场：谁、在做什么、卡在哪

加功能的默认形态是加一个件：先问这件事能不能由某个件提供、经 cordis 的服务送到用得着的地方，能就该是件。拿不准按「不进」处理——加回来永远比拿掉容易。件跑在主进程里、拿得到 `electron`，开窗、菜单、托盘、对话框、子进程全是件的事。

## 刻意不做

下面这些内核没有，不是还没排到，是决定不做；要做得先推翻准入判据。

- **装机**：内核不碰 pnpm，装卸归件——[装机口移除](/trajectory/2026-09-08-no-install-port)
- **自动升级、盘上对账、装失败还原**——[另起一条线](/trajectory/2026-09-07-fresh-line-over-subtraction)、[拆页快照](/trajectory/2026-09-23-future-zone-retired)
- **件之间的准入核对**：件的依赖是件自己的事——[拆页快照](/trajectory/2026-09-23-future-zone-retired)
- **`cordis.yml` 的模板与自愈**：缺了只补空表，读不动就报错——[那面墙](/trajectory/2026-09-07-wall-fresh-home-no-yml)、[拆页快照](/trajectory/2026-09-23-future-zone-retired)
- **界面上的失败兜底**：只读现状之外不归因、不重试、不自动恢复，没有按钮——[阶段页](/trajectory/2026-09-08-stage-page)、[拆页快照](/trajectory/2026-09-23-future-zone-retired)
- **原生命令、宿主子进程、自定义资源协议、日志管道**：内核一条命令都不认，件与页面之间只有三条 IPC 与 `file://`——[单进程重构](/trajectory/2026-09-09-single-process)
- **数据落盘**：内核只给 `dataDir`，落盘归数据件——[数据件](/trajectory/2026-09-07-gwb-data-plugin)
- **打包器**：`tsc` 直出，主进程走正常的包解析，不依赖任何依赖被内联进束——[打包器缓选](/trajectory/2026-09-07-bundler-deferred)

还没定、等前提的那些在[路线](/future/roadmap)。
